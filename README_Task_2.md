# Task 2 – Exploratory Data Analysis (EDA)

## Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on the Netflix Movies and TV Shows dataset using Python.

The objective was to explore the dataset, understand content distribution, identify patterns, and visualize meaningful insights.

## Objectives

- Understand the structure and characteristics of the dataset.
- Analyze Movies and TV Shows distribution.
- Explore content across release years.
- Examine country-wise content distribution.
- Identify popular genres and content ratings.
- Present findings through data visualizations.

## Tools & Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset

The analysis uses the cleaned Netflix dataset containing 8,790 records and 12 columns.

Important attributes include content type, title, country, release year, rating, duration, and genre.

## Analysis Performed

1. Loaded and inspected the cleaned Netflix dataset.
2. Examined data types and dataset dimensions.
3. Analyzed the distribution of Movies and TV Shows.
4. Explored the number of titles across release years.
5. Investigated country-wise content distribution.
6. Analyzed genre and content rating distributions.
7. Created visualizations to communicate the findings.

## Key Findings

- The dataset contains 8,790 titles.
- Movies account for 6,126 titles (69.69%).
- TV Shows account for 2,664 titles (30.31%).
- The analysis explored country contributions, genre representation, and content ratings.
- Visualizations helped identify catalogue distribution and historical patterns.

## Visualizations

The notebook includes charts for exploring:
- Movies vs TV Shows distribution
- Content distribution over release years
- Country-wise catalogue representation
- Genre distribution
- Content rating distribution

## Key Learning Outcomes

- Exploratory data analysis using Pandas.
- Grouping, filtering, and aggregating datasets.
- Identifying patterns and trends.
- Creating visualizations using Matplotlib and Seaborn.
- Communicating analytical findings.
