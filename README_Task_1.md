# Task 1 – Data Cleaning & Preprocessing

## Project Overview

This project focuses on cleaning and preprocessing the Netflix Movies and TV Shows dataset using Python and Pandas.

The objective was to improve data quality, handle missing values, identify duplicate records, and prepare a structured dataset for further data analysis.

## Objectives

- Understand the structure of the dataset.
- Identify and handle missing values.
- Detect and remove duplicate records.
- Clean and standardize relevant columns.
- Prepare the dataset for exploratory data analysis.

## Tools & Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy

## Dataset

The project uses Netflix catalogue data containing information about Movies and TV Shows.

Important columns include:
- Show ID
- Type
- Title
- Director
- Country
- Date Added
- Release Year
- Rating
- Duration
- Listed In

## Data Cleaning Process

1. Loaded the Netflix dataset using Pandas.
2. Inspected dataset dimensions, column names, and data types.
3. Identified missing values across columns.
4. Checked for duplicate records.
5. Handled missing values and standardized the dataset.
6. Extracted duration values and units into separate columns.
7. Prepared the cleaned dataset for subsequent analysis.

## Final Dataset

The cleaned dataset contains:

- **8,790 rows**
- **12 columns**
- No missing values
- No duplicate records

The cleaned dataset was saved as `netflix_cleaned.csv`.

## Outcome

Successfully prepared a structured Netflix dataset that could be reused for exploratory data analysis, recommendation system analysis, trend analysis, and machine learning projects.

## Key Learning

- Data inspection and quality assessment
- Missing-value handling
- Duplicate detection
- Data type conversion
- Feature extraction
- Data preprocessing using Pandas
