# Task 3 – Recommendation System Analysis

## Project Overview

This project explores recommendation system concepts using the Netflix Movies and TV Shows dataset.

The objective was to analyze catalogue information and explore how content attributes can help identify similarities between titles and support content recommendations.

## Objectives

- Understand recommendation system concepts.
- Explore Netflix catalogue attributes.
- Analyze content similarities using available metadata.
- Examine how content information can support recommendation approaches.

## Tools & Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Scikit-learn (if used in the notebook)

## Dataset

The project uses the cleaned Netflix dataset containing 8,790 records and 12 columns.

Relevant attributes include:
- Title
- Type
- Director
- Country
- Release Year
- Rating
- Listed In (genres)

## Analysis Performed

The notebook explores Netflix catalogue information and recommendation-related analysis using available content metadata.

The analysis focuses on understanding how attributes such as genres, country, director, and content type can be used to examine similarities between titles.

## Key Learning Outcomes

- Understanding recommendation system concepts.
- Working with catalogue metadata.
- Exploring content similarities.
- Using Python and Pandas for recommendation-related analysis.
- Understanding the role of content attributes in recommendation approaches.

## Limitations

The dataset does not include user ratings, viewing histories, clicks, or purchase behaviour. Therefore, user-preference-based recommendations and collaborative filtering cannot be validated using this dataset alone.

- `task 3.ipynb` – Jupyter Notebook containing the recommendation system analysis.
