# Task 4 – Trend Prediction Analysis

## Project Overview

This project focuses on analyzing historical trends in the Netflix Movies and TV Shows dataset.

The objective was to explore content trends over time, understand changes in catalogue additions, and examine patterns that could support trend prediction.

## Objectives

- Analyze historical Netflix content data.
- Explore content distribution across years.
- Identify trends and changes over time.
- Apply trend analysis techniques.
- Understand how historical patterns can support forecasting.

## Tools & Technologies

- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn (if used in the notebook)

## Dataset

The project uses Netflix catalogue data containing information about Movies and TV Shows, including release years and dates added to the platform.

## Analysis Performed

1. Loaded and inspected the Netflix dataset.
2. Prepared date-related information for time-based analysis.
3. Analyzed content patterns across years.
4. Visualized historical trends.
5. Explored trend prediction using the methods implemented in the notebook.

## Key Learning Outcomes

- Working with date and time data.
- Grouping and aggregating data by year.
- Identifying historical patterns.
- Visualizing trends.
- Understanding the fundamentals and limitations of trend prediction.

## Limitations

The dataset contains catalogue metadata rather than detailed platform activity. Historical catalogue patterns alone cannot explain changes in subscriber demand, viewing behaviour, or business performance.
